# OOP-mini-terminal-game-project

## Overview

This project is a terminal-based game developed using Object-Oriented Programming (OOP) principles in Python.  
It serves as a practical application to demonstrate the use of classes, inheritance, and encapsulation in building interactive command-line games.

## Features

- **Modular Design**: Utilizes classes to represent game entities and manage game logic.
- **Interactive Gameplay**: Players can interact with the game through terminal inputs.
- **Scalable Architecture**: Designed to easily add new features or game mechanics.

## Getting Started

### Prerequisites

- Python 3.x installed on your system.

### Installation

1. **Clone the repository**
2. **Navigate to the project directory:** cd OOP-mini-terminal-game-project
3. **Run the game:** python main.py

### How to play

Once the game is running in your terminal, follow the on-screen prompts.
Type in the required commands to interact with characters and progress through the game’s scenarios.
